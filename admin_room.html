🛒 Bidhaa Halisi + Link ya Muuzaji

Bidhaa zilizo hapa zinatoka kwenye vyanzo rasmi/marketplaces zilizokaguliwa. Public page inaweza kuonyesha bidhaa; mteja akibonyeza Fungua Mawasiliano anaelekezwa kwenye ada, na backend pekee ndiyo inathibitisha unlock.

🔐 Mfumo wa Mteja → Muuzaji

Hatua 1: Mteja anaona bidhaa → 2: anabonyeza bidhaa → 3: mfumo unaonyesha ada → 4: payment gateway inathibitisha → 5: mawasiliano yanafunguka → 6: mfumo unatuma purchase request kwa muuzaji → 7: live chat/call session inaanzishwa.

Ruhusa ya mawasiliano, seller phone/email na live session zisihifadhiwe/kuachwa wazi kwenye JavaScript public. Zitoe baada ya backend kuthibitisha malipo.
